# Florida State Roleplay

Static information website for https://fsrp.xyz, hosted by GitHub Pages from main / (root).

The root index.html is the homepage. Each section has its own index.html. There is no backend, database, authentication, Render deployment, or browser JavaScript dependency.

Edit server information in reference/*.md, then run npm run build using Node.js. Commit the generated HTML along with the source changes. No npm install is required. Styling is in site.css and supplied artwork is in public/brand.

The original full-stack implementation remains recoverable in Git history. The older project brief is historical; the current scope is an information-only website.
